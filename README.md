# Aradhya Bhardwaj — Interactive Portfolio

A fully redesigned, immersive portfolio built with semantic HTML, custom CSS and vanilla JavaScript.

## Run locally
Open `index.html` with VS Code Live Server, or serve this folder with any static web server.

## Interaction
- Generative particle field reacts to pointer movement.
- Scroll progress indicator and reveal transitions.
- Pointer-follow cursor and project-card tilt on fine-pointer devices.
- Quick navigation palette: press `/` or `Ctrl/Cmd + K`.
- Surprise-me button jumps to a randomly selected project.
- Mobile navigation and responsive layouts.
- Reduced-motion preferences are respected.

## Structure
- `index.html` — content and page structure
- `styles.css` — complete visual system and responsive layout
- `script.js` — interactions and motion
- `assets/` — profile image and résumé

External Google Fonts require an internet connection. No build step or npm dependencies are required.
