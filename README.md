## ◈ About the Project

This repository contains my personal developer portfolio, designed and developed using **HTML5, CSS3, and Vanilla JavaScript**.

The experience combines a futuristic visual identity with interactive elements, motion effects, and a clean content structure to showcase my background, technical capabilities, projects, education, and experience.

The focus is on three things:

- **Visual Experience** — distinctive design, typography, lighting, and motion.
- **Interactivity** — meaningful animations and responsive user interactions.
- **Simplicity** — lightweight architecture without unnecessary frameworks or dependencies.

---

## ✨ Features

| Feature                     | Description                                                                     |
| --------------------------- | ------------------------------------------------------------------------------- |
| ◉ Generative Particle Field | Animated particle network that responds to pointer movement.                    |
| 🌀 Interactive Portrait     | Floating portrait with animated orbital elements and pointer-based 3D movement. |
| 🖱️ Custom Cursor            | Pointer-follow cursor with interactive hover states.                            |
| ⚡ Magnetic Interactions    | Buttons respond dynamically to pointer movement.                                |
| 🎬 Motion Effects           | Cinematic hero entrance, scroll reveals, and smooth transitions.                |
| 🎯 3D Project Cards         | Interactive tilt effects and hover-based visual feedback.                       |
| 📊 Scroll Progress          | Dynamic indicator showing page-reading progress.                                |
| ⌘ Command Palette           | Quick navigation using `/` or `Ctrl/Cmd + K`.                                   |
| 🎲 Surprise Me              | Randomly navigates to a project.                                                |
| 📱 Responsive Layout        | Adaptable experience across desktop, tablet, and mobile.                        |
| ♿ Reduced Motion           | Respects the user's system-level reduced-motion preference.                     |

## 🚀 Getting Started

No framework installation, package manager, or build process is required.

### 1. Clone the repository

```bash
git clone https://github.com/AradhyaBhardwaj/About.git
```

### 2. Navigate to the project

```bash
cd About
```

### 3. Open in Visual Studio Code

```bash
code .
```

### 4. Run locally

Open `index.html` using the **Live Server** extension in VS Code.

Alternatively, open the HTML file directly in your browser.

> **Note:** An internet connection is required to load the externally hosted Google Fonts. The core portfolio does not require npm dependencies.

## 🎨 Design Philosophy

The visual direction combines:

- Dark, immersive backgrounds.
- Violet, cyan, and acid-green accent colours.
- Expressive typography and strong visual hierarchy.
- Subtle gradients, orbital shapes, and glowing details.
- Motion that adds context instead of distracting from content.

The goal is to create a digital experience that feels dynamic while keeping navigation and information accessible.

---

## ⚙️ Performance & Accessibility

The portfolio is built without a heavy frontend framework.

- No npm packages or build pipeline required.
- Responsive layouts for different screen sizes.
- Pointer-specific effects are restricted to fine-pointer devices.
- Reduced-motion preferences are respected.
- Semantic HTML and accessible navigation attributes are used.
