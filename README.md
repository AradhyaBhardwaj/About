# Aradhya Bhardwaj - Portfolio

A responsive single-page developer portfolio built with HTML, custom CSS and
vanilla JavaScript. The page includes animated sections, a circular profile
image, particle effects, project highlights and contact links.

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript
- Bootstrap 5.3
- Bootstrap Icons
- tsParticles
- GSAP
- Google Fonts

The external libraries are loaded from CDNs, so no package installation is
required.

`-- assets/

## Run Locally

From the project folder, start a local server:

```bash
python -m http.server 8000
```

Then open <http://localhost:8000> in a browser. VS Code Live Server can also
be used. Opening `index.html` directly works, but a local server is recommended
for consistent asset loading.

## GitHub Pages Deployment

1. Create a GitHub repository, such as `portfolio`.
2. Upload `index.html`, `styles.css`, `script.js`, `README.md` and the `assets`
   folder.
3. Open **Settings > Pages** in the repository.
4. Select **Deploy from a branch**, choose the `main` branch and the `/ (root)`
   folder.
5. Save the settings and wait for GitHub Pages to publish the site.
